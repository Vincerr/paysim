# paysim
Simulador de transacciones en terminales de autoservicio.
Programa disenado para estimar casos de negocio para clientes en especifico. 
Ayuda a dimensionar el tamano de terminal de autoservicio y sobre todo la frecuencia 
con la que un portavalor deberia ir a recoger todo el dinero recaudado. 

De esta manera se podrian ajustar los precios para obtener licitaciones. 

Utilizar peripherals como libreria.
